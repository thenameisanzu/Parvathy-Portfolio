# Parvathy Vidhu — Portfolio

Modern, high-performance portfolio crafted with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## Features
- **Theme Modes**: Full Light & Dark mode support with zero-FOUC inline hydration script and system preference sync.
- **Micro-Interactions & Animations**: Specular spotlight shine on cards, 3D tilt, magnetic buttons, category filters with smooth layout animations, interactive case study modal dialogs, and continuous marquee.
- **Accessibility (WCAG 2.1 AA)**: Screen-reader-friendly animated text (`Split`), accessible form controls with proper labels, high-contrast ratios in both themes, and full `prefers-reduced-motion` compliance.
- **Live Local Time**: Dynamic Kerala, India (IST) time indicator.
- **SEO Ready**: MetadataBase, OpenGraph, Twitter cards, `robots.ts`, `sitemap.ts`, web manifest, and SVG favicon.
- **Zero Blocking Loaders**: Fast First Contentful Paint (FCP) and Largest Contentful Paint (LCP).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.
